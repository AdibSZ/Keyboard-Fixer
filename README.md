# ⌨️ Keyboard Fixer (تبدیل هوشمند کیبورد)

آیا از تایپ اشتباه متن به دلیل فراموش کردن تغییر زبان کیبورد خسته شده‌اید؟ این ابزار کوچک و سبک دقیقاً برای حل این مشکل ساخته شده است! کافیست متن اشتباه را انتخاب کنید و کلید میانبر را بزنید تا در کسری از ثانیه متن شما به زبان درست تبدیل شود.

## ✨ ویژگی‌ها

* **تشخیص خودکار:** خودش می‌فهمد متن انگلیسی است یا فارسی و برعکس تبدیل می‌کند.
* **رفع تداخل کلیدها:** سیستم هوشمند برای جلوگیری از تداخل با کلیدهای میانبر ویندوز (مثل پنل صدا).
* **رابط کاربری مدرن:** طراحی فلت (Flat) و دارک با گوشه‌های گرد و افکت شیشه‌ای (Translucency).
* **اجرا در پس‌زمینه:** با آیکون System Tray بدون مزاحمت کار می‌کند.
* **اجرای خودکار:** با روشن شدن ویندوز به صورت خودکار فعال می‌شود.
* **شخصی‌سازی:** امکان تغییر کلید میانبر (Hotkey) و تم برنامه.

## 🚀 نصب و راه‌اندازی

### روش اول: دانلود فایل آماده (برای کاربران عادی)

به بخش [Releases](https://github.com/AdibSZ/Keyboard-Fixer/releases) بروید و آخرین نسخه `KeyboardFixer.exe` را دانلود و اجرا کنید.

### روش دوم: اجرای سورس کد (برای توسعه‌دهندگان)

1. پایتون نسخه 3.9+ را نصب کنید.
2. پروژه را کلون کنید:

```bash
git clone https://github.com/YourUsername/Keyboard-Fixer.git
cd Keyboard-Fixer
```

3. کتابخانه‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

4. برنامه را اجرا کنید:

```bash
python main.py
```

## ⚙️ نحوه استفاده

1. متنی که اشتباه تایپ کرده‌اید (مثلاً `sghl` در حالت انگلیسی) را با ماوس انتخاب کنید.
2. کلید میانبر پیش‌فرض (`Ctrl + Alt + Q`) را بزنید. (قابل تغییر در تنظیمات)
3. متن به صورت خودکار به `سلام` تبدیل می‌شود!

> **نکته:** اگر کلید میانبر با برنامه‌ای تداخل داشت، روی آیکون برنامه کنار ساعت کلیک راست کنید و وارد Settings شوید تا آن را تغییر دهید.

## 🛠️ ساخت فایل اجرایی (برای توسعه‌دهندگان)

برای ساخت فایل `.exe` با کمترین حجم از Nuitka استفاده کنید:

```bash
pip install nuitka
python -m nuitka --standalone --onefile --enable-plugin=tk-inter --include-package-data=customtkinter --include-data-files=assets/program.ico=assets/program.ico --windows-icon-from-ico=assets/program.ico --windows-console-mode=disable main.py
```
